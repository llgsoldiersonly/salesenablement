# Retainer Reach Official Workflow v1.0

## Core Philosophy
Video-First + Local Dominance + Emotional Conversion. 
We build trust through video, dominate local search through strategic location clusters, and convert through emotionally intelligent lead magnets and offers.

## Official Execution Order

### Phase 0: Intake
- Client website URL
- Primary practice area(s)
- Target cities and counties
- Current goals

### Phase 1: Research & Foundation
1. **Local-SEO-Analyzer-v3** → Analyze Google, Apple Maps, Bing, directories, reviews, citations
2. **Social-Content-Analyzer** → Analyze YouTube, Instagram, Facebook presence
3. **Brand-Guidelines-Creator** → Establish tone, personality, and messaging
4. **Content-Pillar-Generator** → Build core content pillars

### Phase 2: Conversion Assets
5. **Lead-Magnet-Creator-v3** → Create high-converting emotional lead magnets
6. **Location-Page-Cluster-Strategy** → Design the full local SEO cluster architecture

### Phase 3: Content Creation
7. **Video-First-Hybrid-Creator** (Primary content skill)
8. **YouTube-Content-Creator** (when pure video focus is needed)
9. **SEO-Content-Creator** or **Local-SEO-Content-Brief** (supporting content)
10. **Monthly-Content-Calendar** → Create 30/60/90 day execution plan

### Phase 4: Technical & Website
11. **Local-Schema-Technical-SEO** → Complete technical foundation
12. **Local-Landing-Page-Creator-v2** → Generate city/county landing pages
13. **Website-Transformer-v3** → Create the new homepage + overall site strategy

### Phase 5: Delivery
14. **Master-Orchestrator-v3** → Compile everything into a final client-ready deliverable

## Recommended Default Path (Most Common)
Local-SEO-Analyzer-v3 → Location-Page-Cluster-Strategy → Lead-Magnet-Creator-v3 → Video-First-Hybrid-Creator → Local-Landing-Page-Creator-v2 → Website-Transformer-v3 → Master-Orchestrator-v3

This workflow consistently produces a powerful combination of:
- Local Map Pack dominance
- High-trust video content
- Emotionally optimized lead magnets
- Premium website experience
- Scalable content system
